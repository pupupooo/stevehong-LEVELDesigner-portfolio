# Vehicle Echo Director Lab — 载具事件导演 Demo

## 快速开始

本 demo 会优先读取 `data/district-layout.json`。推荐通过本地服务器打开：

```bash
python3 -m http.server 4180
```

然后访问：

```text
http://localhost:4180/works/vehicle-deck-director/demo/index.html
```

也可以直接打开 `demo/index.html`。在 `file://` 模式下浏览器无法 fetch JSON，页面会自动使用 `data/district-layout.embedded.js` 里的地图镜像。

### 操控

| 按键 | 功能 |
|------|------|
| W / ↑ | 加速 |
| S / ↓ | 刹车 / 倒车 |
| A / ← | 左转 |
| D / → | 右转 |
| E | 接受来电 / 交互 |
| F | 抢夺附近车辆（低速、近距离） |
| Esc | 拒绝 / 取消当前玩法 |

## 系统架构

### 三层分发模型（本 MVP 实现 T2 层）

- **T3 感官回响**（环境底噪）— 未实现，属 Phase 2
- **T2 动态扮演**（Deck 抽牌层）— **本 MVP 核心**
- **T1 系统级挑战**（叙事注入）— 未实现，属远期

### 作品集演示增强

- **简化抢车**: 靠近 NPC 车辆且车速足够低时，按 F 可夺取车辆。
- **车辆身份**: 普通车、跑车、重型车、警车、帮派车会影响驾驶参数与导演推荐。
- **城区布局源事实**: 道路、禁行区、POI、NPC 生成线、玩家出生点和事件锚点统一来自 `data/district-layout.json`。
- **连通城区白盒**: 当前布局为 7200×4800 的手工 JSON，参考涩谷-代官山-惠比寿一带的城市关系，用外环/中环/内环和斜向捷径保证巡航、绕行和追逐空间。
- **世界响应**: 抢车会提升热度，改变右侧面板中的 Deck 上下文权重。
- **LLM 编排建议层**: 展示可传给 LLM 的世界状态输入与 mock 调度建议；当前不依赖真实 API。

### 核心机制

```
驾驶 → 距离/时间计数器累积 → 达到阈值 → 抽牌 → Vehicle Beat signal
                ↑                                      ↓
          速度状态作为修饰器                  E 接入 / Esc 忽略
                                                       ↓
                                                玩法启动 → 世界响应
```

### 触发系统
- **距离驱动**: 净位移 1200-2200px（displacement，非路程）
- **时间驱动**: 18-32s（兜底，保证低速/停留也能触发）
- **取先到者**，触发后两个计数器同时归零
- **速度状态**: >80 km/h 时只作为高速修饰器，不冻结计数器
- **Vehicle Beat signal**: 玩法牌先进入可接入信号，玩家按 E 接入，Esc 忽略
- **玩法进行中**: 计数器锁定（避免任务中触发新任务）

### 牌组构成（11 张/副）

| 玩法 | 张数 | 稀缺度 |
|------|------|--------|
| 午夜竞速 | ×2 | 普通 |
| 恐吓专车 | ×2 | 普通 |
| 拦截运钞车 | ×1 | 稀缺 |
| 副驾指挥 | ×2 | 普通 |
| 空牌（呼吸节奏）| ×4 | 36% |

弃牌重洗：打完整副后原样洗回，保证多样性。

## 4 种可玩玩法

### 午夜竞速 MidnightRace
- **接入**: NPC 改装车从后方逼近闪灯
- **触发**: 玩家加速超过 40km/h 即视为接受
- **玩法**: 3 个检查点竞速，NPC 车 AI 驾驶（速度 = 玩家极速 × 88%）
- **结算**: 先通过最后检查点者胜

### 恐吓专车 IntimidationRide
- **接入**: 手机来电，按 E 接受
- **玩法**: 接到乘客后，通过危险驾驶叠加恐惧值
  - 逆向行驶: +2/s | 碰撞: +15/次 | 高速(>100): +1/s | 急转: +8/次
  - 恐惧值缓慢衰减 -1/s，但不低于历史峰值的 50%
- **结算**: 恐惧值满(100) → 强制停车，乘客下车，任务成功
- **超时**: 3 分钟未完成 → 失败

### 拦截运钞车 ArmoredHeist
- **接入**: 线人来电，按 E 接受
- **玩法**: 运钞车出现，追逐并连续撞击减 HP
  - 伤害 = 撞击速度差 × 0.8
  - 运钞车会逃跑和躲避
- **结算**: HP 归零 → 运钞车撞停，成功
- **失败**: 距离超过 500m → 逃脱

### 副驾指挥 CopilotCommand
- **接入**: 路边 NPC 招手，减速到 <10km/h 接人
- **玩法**: 5 轮方向指令（← / → / ↑），3 秒响应窗口
- **结算**: 完成后开到目的地停车

## 文件结构

```
decksys-mvp/
├── index.html              ← 入口
├── README.md               ← 本文件
├── data/
│   └── district-layout.json ← 城区布局源事实
├── css/
│   └── style.css           ← 暗色调夜景风格
└── js/
    ├── config.js           ← 所有可调参数（速度/触发/牌组/玩法）
    ├── layout.js           ← 读取/校验 district-layout.json
    ├── world.js            ← 事件总线 + 输入 + 布局地图 + 载具物理 + NPC
    ├── renderer.js         ← Canvas 渲染 + 摄像机 + HUD
    ├── deck.js             ← 牌组管理（洗牌/抽牌/弃牌/重洗）
    ├── trigger.js          ← 距离+时间混合触发 + 速度状态
    ├── director.js         ← 导演层（抽牌→Vehicle Beat signal→接入→生命周期）
    ├── encounters.js       ← 4 种可玩玩法实现
    ├── debug.js            ← 右侧导演透视面板
    └── main.js             ← 启动入口 + 游戏循环
```

## 调参指南

所有参数集中在 `js/config.js`，修改后刷新页面即生效：

- `speedGate.threshold` — 高速状态阈值（默认 80 km/h，不冻结计数器）
- `trigger.distanceMin/Max` — 距离触发范围
- `trigger.timeMin/Max` — 时间触发范围
- `deck.composition` — 牌组配比（调整 count 值）
- `beatDefs.*` — Vehicle Beat 事件族、接入信号、POI 偏好和 LLM hint
- `data/district-layout.json` — 道路、建筑禁行区、POI、NPC 生成线、出生点、事件锚点
- `encounters.*` — 各玩法具体参数

## 右侧调试面板说明

面板实时显示系统内部状态，用于演示讲解：

- **速度状态**: 当前速度、高速修饰器、计数器锁定状态
- **触发计数器**: 距离和时间进度条
- **牌组状态**: 剩余/弃牌堆，每张牌可视化
- **导演状态**: 待接入 Vehicle Beat、事件族、POI 来源、修饰器、规则校验或当前玩法阶段
- **LLM 编排建议层**: 世界上下文、Deck 权重和 mock 推荐理由
- **事件日志**: 带时间戳的系统事件流

## 迭代记录

### v0.5 (2026-06-10)
- **Echo Director Lab**: 新增行为 Snapshot、Episode Detector、规则裁决、Echo 写回和下一轮 Beat 偏置展示。
- **场景注入控制**: 支持警局高速、重卡堵银行、居民区危险驾驶和任务保护拒绝推送。
- **LLM-ready 边界**: 当前仍不接真实 LLM；语义推荐为 deterministic mock，规则层负责最终放行。
- **实际分发接入**: Echo 偏置会进入下一次 Deck draw 权重；任务保护开启时，非空 Beat 会被 Policy Gate 拒绝实例化。

### v0.3 (2026-06-06)
- **移除 2D 速度冻结**: 高速只作为调度修饰器，距离/时间计数器继续累计。
- **Vehicle Beat signal**: 玩法牌不再立即启动，而是先生成可接入/可忽略的事件信号。
- **测试城区 MVP**: 加入商业广场、咖啡店、警局、帮派街区、车库、加油站、押运仓库等 POI。
- **LLM 编排建议层**: 右侧面板展示车辆身份、热度、附近 POI、事件族、修饰器和规则层校验。

- **城区布局源事实**: 新增 `data/district-layout.json`，demo 不再把道路/建筑/POI 硬编码在 `world.js`。
