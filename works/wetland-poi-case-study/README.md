# 断流湿地 POI 公开案例页

## 定位

- 用途：Steve 的个人关卡设计求职作品；
- 载体：公开静态 HTML 案例页，也支持离线打开；
- 核心素材：2026-07-30 录制的 UE 5.5 白盒完整流程；
- 使用边界：个人非商业 Demo。动物与角色为原型占位资源，不作为原创资产或商业项目成果展示。

## 打开方式

直接双击 `index.html`。页面不依赖网络或外部字体，章节按钮与视频同步脚本可在本地文件模式运行。

公开站点路径：`/works/wetland-poi-case-study/`。

若浏览器限制本地 WebVTT 章节轨道，右侧章节按钮仍然可用；也可在本目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。

## 文件

- `index.html`：案例页结构与正式中文文案；
- `styles.css`：响应式、键盘焦点、减少动态效果与打印样式；
- `app.js`：视频章节跳转、当前章节和水位标尺同步；
- `chapters.vtt`：标准 WebVTT 章节；
- `assets/wetland-poi-walkthrough.mp4`：压缩后的完整 2:22 实机流程；
- `assets/*.webp`：来自同一录像的关键帧。
