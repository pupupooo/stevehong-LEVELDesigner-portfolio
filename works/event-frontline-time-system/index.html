01 / DESIGN PROBLEM

自然时间为什么仍然不自然

连续流动容易让世界看起来“活着”，却可能只是在重复日常循环；行动推进容易控制内容密度，却会让时间像菜单资源。本原型尝试的不是二选一，而是明确两套时间各自负责什么。

世界持续流动

如果结果不累计，玩家不触发主线时，大世界只是在重复同一天。

行动推动时间

内容容易收束，但移动和探索都像在支付点数，3D 空间的连续感被打断。

硬倒计时施压

时间有机会成本，却也迫使玩家跳过观察，削弱探索和局部决策的价值。

世界时间负责让事件成熟，现场时间负责让玩家决策；两者在写回节点重新汇合。

02 / TIME MODEL

双层时间结构

系统只保留少量阶段和局部规则。复杂感不来自为每条支线编写完整分支，而来自事件成熟、玩家位置、角色意图和资源归属之间的组合。

03 / PLAYABLE PROOF

同一事件，三种收敛

Demo 不是叙事展示器，而是规则对照实验。玩家可以直接在地图移动、观察预兆，并在药车伏击现场点击山贼、药车和药箱。

THREE CONTRAST ROUTES

玩家改变的不是剧情选项，而是现场关系

四种交互原语作用于角色意图、抵达时序和资源所有权。结果不会停在结算弹窗，而会继续改变医馆、市集、官署和山路。

A
警告药车 + 拖住山贼

药车脱离伏击，救援路线保住。

B
识别目标 + 抢救药箱

药车失守，但药箱成为可携带资源；送到医馆后形成部分成功。

C
错过或未观察现场

事件照常写回；根据玩家是否见过预兆，生成强后果入口或弱传闻。

04 / LOCAL RULES

用简单规则制造戏剧差异

原型不模拟所有角色的完整人生，只维护足以产生后果的局部状态。每条规则都能直接映射到画面、交互与世界写回。

RULE 01阶段成熟

事件前线只经过预兆、现场、写回、重接和定局五个阶段。

RULE 02局部阈值

角色意图、时间差和资源归属决定三拍后的结果，不枚举完整剧情树。

RULE 03痕迹衰减

玩家见过预兆或亲历失败时，后果会以更强入口重新接近玩家。

RULE 04结果写回

成功、部分成功和错过都会改变地点标签、NPC 状态和后续入口。

05 / VALIDATION BOUNDARY

原型证明了什么，还没证明什么

这部分决定它能否作为作品，而不是概念图。左侧是当前可直接操作和复现的证据；右侧是仍需继续验证的系统规模问题。

已验证

在单个事件前线与六区小镇中可稳定复现。

  • 场外世界自然流动，角色位置随 tick 改变
  • 玩家进入现场后，世界时间立即暂停
  • 每次行动只推进一个离散节拍
  • 玩家能改变角色意图与资源所有权
  • 结果写回地点，并生成不同强度的重接入口

尚未验证

这些内容属于后续系统方向，不伪装成当前成果。

  • 多条事件前线争夺同一角色与资源时的稳定性
  • 数十天尺度下的状态累积、遗忘与存档成本
  • 3D 连续移动中，预兆和后果入口的空间可读性
  • 批量生产事件内容所需的配置工具与调试界面
  • 玩家长期利用暂停机制时的节奏与平衡问题
CONCLUSION

自由不是让所有事情等待玩家，而是让世界继续变化，同时把可理解、可介入的后果送回玩家身边。

事件前线把连续时间的自然感与离散决策的可控性分工处理。它目前是一套小规模、可验证的系统假设，而不是对完整开放世界的替代方案。
